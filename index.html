🎨 מדריך אפליקציית בחירת צבעים

מדריך שלב אחר שלב ליצירת אפליקציה אינטראקטיבית

📋 הכנה

הורידו את תמונות הצבעים:

הורידו את 6 קבצי התמונה הבאים (קישורים יסופקו):

  • red_circle.png
  • blue_circle.png
  • green_circle.png
  • yellow_circle.png
  • purple_circle.png
  • orange_circle.png

שמרו אותם במקום שתוכלו למצוא אותם בקלות.

שלב 1: צרו פרויקט חדש

✏️ עשו:

  1. פתחו את Android Studio
  2. לחצו על "New Project"
  3. בחרו "Empty Views Activity"
  4. תנו לפרויקט שם "ColorPicker"
  5. לחצו "Finish"

💡 שימו לב:

פתחו את activity_main.xml והסתכלו על האלמנט הראשי. ברירת המחדל עבור Empty Views Activity היא ConstraintLayout. זה מה שנעבוד איתו!

שלב 2: הוסיפו תמונות לפרויקט

✏️ עשו:

  1. ב-Android Studio, מצאו את חלון Project בצד שמאל
  2. נווטו אל app > res > drawable
  3. לחצו לחיצה ימנית על תיקיית drawable
  4. בחרו "Reveal in Finder" (Mac) או "Show in Explorer" (Windows)
  5. העתיקו את כל 6 תמונות העיגולים הצבעוניים לתיקייה הזו
  6. חזרו ל-Android Studio - אתם אמורים לראות את התמונות מופיעות בתיקיית drawable

💡 שימו לב:

תיקיית drawable היא המקום שבו כל התמונות והגרפיקה של האפליקציה שלכם נמצאים. Android Studio מזהה אותם אוטומטית ועושה אותם זמינים לשימוש.

שלב 3: הוסיפו ImageView ראשון

✏️ עשו:

  1. פתחו את activity_main.xml במצב Design (לחצו על הלשונית "Design" בחלק העליון)
  2. הסתכלו על חלון Palette בצד שמאל
  3. לחצו על קטגוריית "Common" (או "Images & Media")
  4. מצאו ImageView ברשימה
  5. גררו ImageView אל המסך

💡 שימו לב:

ל-Palette יש שני חלקים:

  • צד שמאל: מציג קטגוריות של views
  • צד ימין: מציג views ספציפיים כשאתם בוחרים קטגוריה
שלב 4: הגדירו את מקור התמונה

✏️ עשו:

  1. וודאו שה-ImageView שלכם נבחר
  2. הסתכלו על חלון Attributes בצד ימין
  3. בחלק העליון של חלון Attributes, מצאו את תיבת החיפוש
  4. הקלידו src בתיבת החיפוש
  5. מצאו את ה-attribute בשם src ולחצו על התפריט הנפתח
  6. בחרו @drawable/red_circle

💡 שימו לב:

src מייצג את המילה "source" (מקור) - הוא אומר ל-ImageView איפה למצוא את התמונה. הערך @drawable/red_circle אומר "חפש בתיקיית drawable את הקובץ בשם red_circle."

תיבת החיפוש בחלון Attributes עוזרת לכם למצוא במהירות attributes ספציפיים במקום לגלול דרך מאות אפשרויות. זה חוסך המון זמן!

שלב 5: הפכו את ה-ImageView ללחיץ

✏️ עשו:

  1. כשה-ImageView עדיין נבחר
  2. בתיבת החיפוש של Attributes, הקלידו clickable
  3. מצאו את ה-attribute בשם clickable והגדירו אותו ל-true (סמנו את התיבה)
  4. חשוב: לחצו על ה-X או כפתור הניקוי כדי לסגור את החיפוש

💡 שימו לב:

⚠️ תמיד זכרו לסגור את החיפוש כשסיימתם!

אם תשכחו לסגור אותו ותחפשו משהו אחר מאוחר יותר, זה לא בהכרח יופיע ותתבלבלו למה אתם לא מוצאים את מה שאתם מחפשים.

שלב 6: הוסיפו עוד ImageViews

✏️ עשו:

  1. גררו עוד 5 ImageViews אל המסך
  2. לכל אחד, הגדירו את ה-attribute src לצבע שונה:
    • ImageView 2: @drawable/blue_circle
    • ImageView 3: @drawable/green_circle
    • ImageView 4: @drawable/yellow_circle
    • ImageView 5: @drawable/purple_circle
    • ImageView 6: @drawable/orange_circle
  3. הפכו כל אחד ל-clickable = true
  4. כשאתם גוררים אותם, נסו למקם אותם בערך ב-2 שורות של 3

💡 שימו לב:

כשאתם גוררים את ה-ImageViews במסך, קווי עזר דקים מופיעים באופן זמני. קווים אלה עוזרים לכם:

  • ליישר את ה-views שלכם עם views אחרים (יישור קצוות או מרכזים)
  • ליצור ריווח אחיד בין views

קווי עזר אלה הם מדריכים זמניים - הם נעלמים כשאתם משחררים את ה-view.

שלב 7: בחירה מרובה ב-Component Tree

✏️ עשו:

  1. הסתכלו על חלון Component Tree (בדרך כלל בצד שמאל, מתחת או ליד ה-Palette)
  2. לחצו על ה-ImageView הראשון ב-Component Tree
  3. החזיקו Ctrl (Windows) או Cmd (Mac)
  4. בזמן שאתם מחזיקים, לחצו על 5 ה-ImageViews האחרים
  5. כל 6 אמורים להיות מודגשים/נבחרים עכשיו

💡 שימו לב:

ה-Component Tree מציג את הפריסה שלכם כהיררכיה. הרבה יותר קל ואמין לבחור מספר views כאן מאשר לנסות ללחוץ עליהם ב-canvas של ה-Designer.

זו אחת הטריקים השימושיים ביותר לעבודה יעילה!

שלב 8: יישרו את ה-ImageViews

✏️ עשו:

  1. כשכל 6 ה-ImageViews עדיין נבחרים, הסתכלו על סרגל הכלים בחלק העליון של ה-Designer
  2. אתם אמורים לראות אייקוני יישור חדשים שהופיעו
  3. לחצו על האייקון "Align horizontally" (או "Align tops" - התנסו באפשרויות יישור שונות)
  4. ראו איך ה-views מתיישרים!

💡 שימו לב:

כשאתם בוחרים מספר views, סרגל כלים מיוחד מופיע עם כלי יישור וחלוקה.

הכלים האלה מופיעים רק כאשר מספר views נבחרים!

שלב 9: חלקו באופן שווה

✏️ עשו:

  1. ודאו שה-6 ImageViews שלכם עדיין נבחרים
  2. באותו סרגל כלים, מצאו את האייקון "Distribute horizontally" או "Distribute vertically"
  3. לחצו עליו כדי ליצור ריווח שווה בין ה-views שלכם

💡 שימו לב:

כלי ה-Distribute יוצר ריווח אחיד לחלוטין בין views באופן מיידי.

זה שימושי במיוחד עבור פריסות כמו רשתות, לוחות כפתורים, או כל עיצוב שבו אתם רוצים ריווח עקבי. בלי הכלי הזה, הייתם צריכים להתאים ידנית את ה-margins עבור כל view!

שלב 10: Infer Constraints

✏️ עשו:

  1. לחצו איפשהו על הרקע כדי לבטל את הבחירה של ה-ImageViews
  2. הסתכלו על סרגל הכלים של Designer בחלק העליון
  3. מצאו ולחצו על האייקון "Infer Constraints" (נראה כמו שרביט קסמים עם קווים)
  4. צפו כשקווי constraint מופיעים ומחברים את ה-views שלכם!

💡 שימו לב:

Infer Constraints הוא אחד הכלים החזקים ביותר של ConstraintLayout!

הוא יוצר אוטומטית constraints על בסיס מיקומי ה-views הנוכחיים שלכם. זה חוסך לכם מליצור ידנית כל constraint בנפרד.

ממש לידו, תראו את האייקון "Clear All Constraints". זה מסיר את כל ה-constraints אם אתם צריכים להתחיל מחדש.

🎯 שלב אופציונלי:

נסו ללחוץ על "Clear All Constraints" - צפו איך כל קווי ה-constraint נעלמים!

ואז לחצו שוב על "Infer Constraints" כדי ליצור אותם מחדש. זה מראה לכם כמה קל להתנסות ולאתחל.

שלב 11: בדקו את ה-XML

✏️ עשו:

  1. בחלק העליון של העורך, לחצו על לשונית "Code" (ליד "Design" ו-"Split")
  2. הסתכלו על קוד ה-XML של ה-ImageViews שלכם
  3. מצאו את ה-constraint attributes - הם מתחילים עם layout_constraint

💡 שימו לב:

כל constraint attribute מחבר קצה אחד של ה-view שלכם לקצה של view אחר (או של ה-parent).

לדוגמה: layout_constraintTop_toBottomOf="@id/imageView2" אומר "חבר את הקצה העליון שלי לקצה התחתון של imageView2."

ה-constraint attributes העיקריים:

  • layout_constraintTop_toTopOf - מחבר את הקצה העליון לחלק העליון של view אחר
  • layout_constraintTop_toBottomOf - מחבר את הקצה העליון לחלק התחתון של view אחר
  • layout_constraintBottom_toTopOf - מחבר את הקצה התחתון לחלק העליון של view אחר
  • layout_constraintBottom_toBottomOf - מחבר את הקצה התחתון לחלק התחתון של view אחר
  • layout_constraintStart_toStartOf - מחבר את הקצה ההתחלתי לתחילה של view אחר
  • layout_constraintStart_toEndOf - מחבר את הקצה ההתחלתי לסוף של view אחר
  • layout_constraintEnd_toStartOf - מחבר את הקצה הסופי לתחילה של view אחר
  • layout_constraintEnd_toEndOf - מחבר את הקצה הסופי לסוף של view אחר

שימו לב גם: ה-Designer מייצר XML, אבל הוא לא תמיד שם attributes בסדר הגיוני או עקבי. ה-attributes עשויים להיות מעורבבים או מפוזרים. זה

🎯 אופציונלי (מתקדם):

אם אתם רוצים לשמור על ה-XML שלכם מסודר ומאורגן, אתם יכולים לסדר מחדש ידנית את שורות ה- XML כדי לקבץ אותם בצורה הגיונית (כל ה-constraints ביחד, כל ה-sizing attributes ביחד וכו').

זה לא נדרש, אבל חלק מהמפתחים מעדיפים XML מאורגן.

שלב 12: הוסיפו קוד Java

✏️ עשו:

  1. פתחו את MainActivity.java
  2. הוסיפו את הקוד הבא בתוך מתודת onCreate, אחרי setContentView:
// Find all ImageViews ImageView redCircle = findViewById(R.id.imageView); // Adjust IDs as needed ImageView blueCircle = findViewById(R.id.imageView2); ImageView greenCircle = findViewById(R.id.imageView3); ImageView yellowCircle = findViewById(R.id.imageView4); ImageView purpleCircle = findViewById(R.id.imageView5); ImageView orangeCircle = findViewById(R.id.imageView6); // Get the main layout ConstraintLayout mainLayout = findViewById(R.id.main); // Set click listeners redCircle.setOnClickListener(v -> mainLayout.setBackgroundColor(Color.RED)); blueCircle.setOnClickListener(v -> mainLayout.setBackgroundColor(Color.BLUE)); greenCircle.setOnClickListener(v -> mainLayout.setBackgroundColor(Color.GREEN)); yellowCircle.setOnClickListener(v -> mainLayout.setBackgroundColor(Color.YELLOW)); purpleCircle.setOnClickListener(v -> mainLayout.setBackgroundColor(Color.parseColor("#800080"))); orangeCircle.setOnClickListener(v -> mainLayout.setBackgroundColor(Color.parseColor("#FFA500")));
  1. ודאו שאתם מוסיפים את ה-imports האלה בחלק העליון של הקובץ:
import android.graphics.Color; import android.widget.ImageView; import androidx.constraintlayout.widget.ConstraintLayout;

💡 שימו לב:

ייתכן שתצטרכו להתאים את ה-IDs של ה-ImageView (imageView, imageView2 וכו') כדי להתאים למה ש-Android Studio יצר עבור ה-views שלכם.

בדקו ב-XML כדי לראות את ערכי ה-android:id המדויקים.

שלב 13: הריצו את האפליקציה!

✏️ עשו:

  1. לחצו על כפתור "Run" הירוק (אייקון play) בחלק העליון של Android Studio
  2. בחרו את האמולטור או המכשיר המחובר שלכם
  3. חכו שהאפליקציה תיבנה ותותקן
  4. נסו ללחוץ על כל עיגול צבעוני!

💡 שימו לב:

🎉 בניתם אפליקציה עובדת!

יצרתם ממשק משתמש, הגדרתם constraints ל-views, והוספתם פונקציונליות אינטראקטיבית.

זוהי דוגמא ל מחזור שלם של פיתוח Android.

✅ מה למדתם

✓ איך להשתמש ב-Palette כדי להוסיף views

✓ איך להשתמש בחיפוש ב-Attributes כדי למצוא properties במהירות

✓ איך להשתמש ב-Component Tree לבחירה מרובה

✓ איך קווי עזר ליישור מנחים את הפריסה שלכם

✓ איך להשתמש בכלי Align ו-Distribute לפריסות מושלמות

✓ איך Infer Constraints יוצר אוטומטית constraints

✓ מהם ה-constraint attributes העיקריים

✓ איך לחבר קוד Java ל-views ב-XML

✓ איך לבנות אפליקציית Android שלמה ועובדת!
